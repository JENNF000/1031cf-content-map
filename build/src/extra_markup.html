    Labels

    Sync settings

    Your labels, comments and moves are always saved on this device first. Connecting a GitHub repo also pushes them to annotations.json, so your phone and laptop stay in step — and so the weekly rebuild can read what you've marked.

    Use a fine-grained personal access token scoped to this one repository, with Contents: Read and write and nothing else. It's stored in this browser only — never in the repo, never sent anywhere but github.com. Revoke it any time from your GitHub settings.
