# 1031cf-content-map

Private working tool: 1031 Crowdfunding organic content topic map (v2, Aug 2026).
14 topic clusters × 4 tiers (Transactional / Pillar / Fan-out / Redirect), joined
to SEMrush data, with audit insights and a verified-redirects register.

- `data.json` — machine-owned; replaced by the weekly build. Never edit by hand.
- `annotations.json` — **Jennifer's notes.** Written by the app. Builds must never touch it.
- `index.html`, `app.js`, `sw.js`, `manifest.webmanifest`, `icons/` — the app.
- Served by GitHub Pages; `robots.txt` + a noindex meta keep it out of search
  results (that is not access control — the URL is public).
